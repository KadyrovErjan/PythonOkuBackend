## 🌐 API Endpoints

### Аутентификация
```
POST   /api/v1/auth/login/      # Вход в систему
POST   /api/v1/auth/refresh/    # Обновление токена
POST   /api/v1/auth/logout/     # Выход
```

### Управление пользователями (только директор)
```
GET    /api/v1/users/           # Список всех работников
POST   /api/v1/users/           # Создать нового работника
GET    /api/v1/users/me/        # Мой профиль
PATCH  /api/v1/users/me/        # Обновить мой профиль
PATCH  /api/v1/users/me/change-password/  # Сменить пароль
```

### Пример создания нового работника
```json
POST /api/v1/users/
Authorization: Bearer <access_token>

{
  "login": "kassir1",
  "password": "secure_password123",
  "full_name": "Айгуль Иванова",
  "role": "cashier",
  "is_active": true
}
```

**Доступные роли:**
- `cashier` - Кассир
- `accountant` - Бухгалтер
- `director` - Директор

## 🔧 Команды для управления

### Запуск сервера
```powershell
cd backend
python manage.py runserver 8000
```

### Очистка БД и создание нового владельца
```powershell
cd backend
python manage.py init_owner
```

### Применение миграций
```powershell
cd backend
python manage.py migrate
```

### Создание миграций
```powershell
cd backend
python manage.py makemigrations
```

## 🎯 Следующие шаги

### 1. Вход в систему
Используйте данные директора для входа через API:
```bash
curl -X POST http://127.0.0.1:8000/api/v1/auth/login/ \
  -H "Content-Type: application/json" \
  -d '{"login": "director", "password": "director2025"}'
```

### 2. Создание работников
После входа директор может создавать работников через:
- API endpoint `/api/v1/users/`
- Админ-панель Django: http://127.0.0.1:8000/admin

### 3. Frontend
Frontend должен быть создан отдельно в папке:
```
C:\Users\USER\Desktop\ITADISCRMFrontend
```
